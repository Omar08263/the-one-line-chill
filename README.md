One Line, One Chill: a program that writes one text to `/output/entry.txt` — one original horror line, a single sentence under 200 characters.

> The radiologist slid my chest X-ray across the desk and tapped the small hand gripping my ribs from the inside.

## Run it

```sh
python3 main.py
```
